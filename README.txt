RFN Mod Launcher v0.2.0 — автообновление мода
==============================================

Что изменилось:
- лаунчер умеет автоматически получать актуальный QoL SWF с твоего сервера;
- проверка выполняется по SHA-256, поэтому один и тот же файл повторно не скачивается;
- обновление выбирается под ТОЧНЫЙ официальный release, который запросила игра;
- если сеть/сервер обновлений недоступны, используется последняя локальная копия;
- если локальной копии нет, для release 1401 есть встроенный fallback RFN QoL v0.9.15;
- новый официальный release не будет случайно запущен со старым патчем.

Один раз для владельца мода:
1. Загрузи содержимое папки server/ на любой HTTPS-сайт, сохраняя файлы рядом:
   manifest.json
   client_release1401.swf
   RFN_v0915_patch_notes.txt
2. В RFNModLauncher.update_url.txt укажи полный URL до manifest.json.
   Например:
   https://example.com/rfn-mod/manifest.json
3. Раздай друзьям:
   RFNModLauncher.exe
   RFNModLauncher.update_url.txt
   Их надо положить рядом с RaceForNuts.exe.

Дальше обновления:
- мы делаем новую версию SWF;
- ты заменяешь SWF на сервере и обновляешь manifest.json (version/hash/size);
- друзьям НИЧЕГО пересылать не надо;
- при следующем запуске лаунчер сам скачает новую версию в patched/.

Если официальный клиент обновился, например до release 1402:
- до появления записи 1402 в manifest.json лаунчер не станет подсовывать ему 1401;
- после нашего порта добавляешь release 1402 в manifest и файл client_release1402.swf;
- у всех он подтянется автоматически.

Manifest поддерживает относительный URL файла, поэтому папку server/ можно переносить между доменами без правки поля url.

Переменная окружения RFN_MOD_MANIFEST_URL имеет приоритет над update_url.txt.
